Running imintty

First off, instead of installing imintty manually, consider installing it through the MinGW installer, using mingw-get install msys-imintty.

Otherwise, you need to ensure that Windows is able to find the MSYS DLL (msys-1.0.dll) when starting imintty.exe. There are several ways to do this:

  • Start it from within an existing MSYS session.
  • Create a shortcut to msys.bat with the additional parameter --imintty.
  • Create a shortcut to imintty.exe with the parameter /bin/bash -l.
  • Place imintty.exe alongside msys-1.0.dll in the MSYS /bin directory and start it from there.
  • Add the MSYS /bin directory (e.g. C:\MSYS\bin) to the Windows PATH variable, which can be found under 'Environment Variables' on the 'Advanced' tab of the System Properties control panel.

Invoke imintty as follows to obtain a login shell that sources all the usual startup scripts: imintty /bin/bash -l

Invoking imintty with --version or --help will print version or usage information. The imintty manual can be found on the home page at http://imintty.github.io/.
